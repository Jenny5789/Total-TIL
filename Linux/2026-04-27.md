## 📝 [vi 연습 문제 - Vim Training Mission: KB Good Job Fair 2026]

### 1. 실습 파일 만들기 (job_fair.txt)

터미널에서 아래 내용을 입력하여 연습용 파일을 생성하세요:

```bash
cat <<END > job_fair.txt
Event: KB Good Job Fair 2026
Location: COEX Hall A
Goal: Networking & Job Hunting
Tasks:
- Resume printing
- Visit Team Fit Connect Zone
- Ask about salary and benefits
- Prepare for mock interviews
- Visit booth of company X
- Grab some freebies
END
```

### 2. Vim 실습 미션 (`vi job_fair.txt` 입력 후 시작)

✅ [미션 1: 항목 수정]

- 목표: `Visit booth of company X`의 X를 원하는 회사명(Google 등)으로 바꾸기
- 방법: 해당 줄 이동(`j`) → `X` 위에 커서 두고 `cw` 입력 → 회사명 입력

✅ [미션 2: 중요도 우선순위 정하기]

- 목표: `Resume printing`을 맨 위로 옮기기
- 방법: 줄 이동 → `dd` (삭제/잘라내기) → `gg` (맨 위 이동) → `p` (붙여넣기)

✅ [미션 3: 오늘 할 일 추가]

- 목표: 리스트 맨 아래에 `- Bring a pen` 추가하기
- 방법: `G` (맨 아래 이동) → `o` (새 줄 생성) → `- Bring a pen` 입력 → `ESC`

✅ [미션 4: 불필요한 항목 삭제]

- 목표: `Grab some freebies` 삭제하기
- 방법: 해당 줄 이동 → `dd`

### 3. 필수 단축키 요약

| 동작 | 단축키 |
|------|--------|
| 이동 | `h`(좌), `j`(하), `k`(상), `l`(우) |
| 맨 위/아래 이동 | `gg` / `G` |
| 줄 삭제 | `dd` |
| 붙여넣기 | `p` |
| 수정 시작 | `i` (현재 위치) / `o` (아래 줄 추가) |
| 저장/종료 | `:wq` |
| 실수 취소 | `u` |

## 실습 정리

> `ls -l job_fair.txt`
> - 5번째 나온 `0`은 파일의 크기를 의미
> - 0인 것을 보아 파일은 생성했지만 입력된 내용은 저장이 안됨

> `cat job_fair.txt`
> - **파일의 내용 출력**
> - 파일이 비어있어 아무것도 출력되지 않음 (내용 저장 전)

> `vi job_fair.txt`
> - vi 에디터로 파일을 연다

> `mkdir practice`
> - `practice`라는 **디렉토리(폴더)를 생성**

> `mv job_fair.txt practice.txt`
> - `mv [파일] [이름]` 입력하면 **파일의 이름을 변경**
> - `mv job_fair.txt practice.txt practice/` → 파일 두 개를 이동 (경로 끝에 `/` 작성)

> `pwd`
> - 현재 경로 확인(위치확인)

> `cd practice`
> - `practice` 디렉토리 안으로 이동

> `ls`
> - 현재 디렉토리 파일 목록 보기
