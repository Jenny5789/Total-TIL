## 주요 학습 내용

### VI 에디터 모드 전환

```
일반 모드 (Esc) ──▶ 입력 모드 (i / a / o) ──▶ 명령 모드 (:wq / :q!)
```

### VI 핵심 단축키 요약

| 분류 | 단축키 | 설명 |
|------|--------|------|
| 입력 | `i` / `a` / `o` | 현재 위치 / 다음 칸 / 새 줄 입력 |
| 삭제 | `x` / `dd` | 글자 1개 / 줄 전체 삭제 |
| 복사/붙여넣기 | `yy` / `p` / `P` | 복사 / 아래 붙이기 / 위 붙이기 |
| 이동 | `gg` / `G` / `0` / `$` | 문서 처음 / 끝 / 줄 처음 / 줄 끝 |
| 검색 | `/단어` + `n` / `N` | 검색 후 다음 / 이전 결과 |
| 치환 | `:%s/A/B/g` | 문서 전체 A → B 치환 |
| 저장 | `:wq` / `:q!` / `:w` | 저장+종료 / 강제종료 / 저장만 |

### Linux 기본 명령어 요약

| 명령어 | 설명 |
|--------|------|
| `pwd` | 현재 위치 확인 |
| `ls` / `ls -l` | 목록 / 상세 목록 |
| `mkdir` | 폴더 생성 |
| `cd` / `cd ..` | 폴더 이동 / 상위 폴더 |
| `touch` | 파일 생성 |
| `mv` | 파일 이동 또는 이름 변경 |
| `cat` / `cat >` | 파일 내용 출력 / 파일 생성+입력 |
| `head -n N` / `tail -n N` | 앞 N줄 / 뒤 N줄 출력 |
| `grep` | 문자열 검색 |
| `rm` / `rmdir` | 파일 삭제 / 빈 폴더 삭제 |
