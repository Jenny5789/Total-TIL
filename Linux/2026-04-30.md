## 📂 문제 1: 파일 & 디렉토리

🚩 **목표:** 디렉토리 생성, 파일 관리, 파일 내용 확인 및 검색 명령어 익히기

💻 **[실습 내용]**

- `linux_practice` 디렉토리 생성
- `day1` 디렉토리 생성 후 이동
- 파일 생성: `notes.txt`

✅ **미션**

1. `mkdir` 명령어를 사용하여 `linux_practice` 디렉토리를 생성합니다.
2. `day1` 디렉토리를 생성한 뒤 해당 디렉토리로 이동합니다.
3. `touch` 명령어를 사용하여 `notes.txt` 파일을 생성합니다.
4. `ls` 명령어로 파일 목록을 확인합니다.
5. `mv` 명령어를 사용하여 `notes.txt` 파일명을 `0430.txt`로 변경합니다.

---

## 📂 문제 2: 파일 내용 보기 & 검색

💻 **[실습 텍스트]**

```
error: failed login
info: user logged in
warning: disk low
error: timeout
info: process done
```

✅ **미션**

1. `cat > log.txt` 명령어를 사용하여 파일을 생성하고 위 내용을 입력합니다.
2. `cat` 명령어로 파일 전체 내용을 확인합니다.
3. `head -n 2` 명령어로 상위 2줄을 출력합니다.
4. `tail -n 2` 명령어로 하위 2줄을 출력합니다.
5. `grep error log.txt` 명령어로 `"error"`가 포함된 줄만 검색합니다.
