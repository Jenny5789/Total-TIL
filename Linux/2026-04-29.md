## 📝 [vi 연습 문제 - Line Visual & 들여쓰기]

🚩 **목표:** 비주얼 모드 활용과 코드 블록의 구조적 편집(들여쓰기/복사/붙여넣기) 익히기

💻 **[실습 텍스트]**

```python
if __name__ == "__main__":
print("Start")
data_load()
process_data()
save_result()
print("End")
```

✅ **미션**

1. `V` 모드로 함수 내용(`print`~`save_result`) 4줄을 선택한 뒤, `>>`를 눌러 들여쓰기를 수행합니다.
2. 들여쓰기 된 상태에서 다시 `<<`를 눌러 원상복구합니다.
3. `V` 모드로 4줄을 선택하고 `y`를 눌러 복사한 뒤, 맨 아래에 `p`를 2번 눌러 중복 코드 덩어리를 만듭니다.

## 📝 [vi 연습 문제 3: 라인 내 치환(Substitute)의 정밀함]

🚩 **목표:** 특정 라인 내에서 문자열을 검색하고 치환하는 정밀한 조작 익히기

💻 **[실습 텍스트]**

```
error: log_file_01.txt, severity: low
error: log_file_02.txt, severity: low
error: log_file_03.txt, severity: low
```

✅ **미션**

1. 첫 줄에서 `:s/low/high/`를 입력해 `low` 하나만 `high`로 변경합니다.
2. 두 번째 줄에서 `:s/low/high/g`를 입력하여 한 줄에 여러 개의 `low`가 있다면 전부 변경되는지 확인합니다.
3. 세 번째 줄에서 `:s/log/LOG/`를 수행하고, 바로 `u`를 눌러 복구한 뒤 다시 수행해 봅니다.
